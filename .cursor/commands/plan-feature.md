# Plan a feature
Read tools/agent-workflow/guide.md.
Use the user's feature description and acceptance criteria. Ask for missing requirements only when they change the solution.
Search for the relevant package, symbols and an existing example before opening files. Avoid full-repository reads.
Produce at most five steps, naming likely files, the expected behavior and the checks needed. Identify any dependency, database or public API change.
Stop after the plan. Do not edit files until the user requests implementation.
