# Investigate an issue
Read tools/agent-workflow/guide.md.
Ask for the error, expected behavior and a minimal reproduction if missing.
Search for the relevant code and inspect useful logs supplied by the user. Do not dump secrets or scan every package.
Separate observed facts from hypotheses. Propose the smallest explanation and a focused check to confirm it. Then propose a fix and its verification.
Do not make broad refactors or unrelated changes. Apply the fix only when the user asks you to proceed.
